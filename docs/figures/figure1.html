Central Goal
A centralized, efficient, and accessible digital solution for managing school sports activities at SNNHS
INPUT
Administrator Data
  • Sports programs and athlete profiles
  • Coach records and event schedules
  • Medical and injury records
  • Achievements and credentials
Student Application Form
  • Personal details and student ID
  • Grade level and gender
  • Sport of interest
  • Contact details and email
Eligibility Documents
  • Medical certificate (fit to play)
  • PSA birth certificate
  • Parent's/guardian's consent form
No account is created at this stage. After submission, the system issues a unique reference number so the applicant can securely check their application status.
PROCESS
Public Landing Page Module
  • Announcements and sports programs
  • Application form and uploads
  • Secure status check (reference + email)
  • Login and password recovery
Athlete Module
  • Dashboard, schedules, calendar
  • Attendance check-in and records
  • Achievements and certificates
  • Application status and notifications
Administrator Module
  • Review, approve, reject, or request revision
  • Status history, notes, and office instructions
  • Sports, coaches, events, attendance
  • Medical records, certificates, notifications
Modules run on PHP 8.2 and Laravel 12 (MVC) with role-based access, validation, and audit-oriented status tracking.
OUTPUT
Organized Records
  • Athlete registry and coach directory
  • Application records and status history
  • Attendance, medical, and participation records
Reports and Documents
  • Athlete, coach, and attendance lists
  • CSV and PDF export options
  • Official achievement certificates
  • Application reference/status feedback
User Interfaces
  • Public landing page and status check page
  • Athlete dashboard and application view
  • Administrator command centre
  • In-app notification feed
EVALUATION
ISO/IEC 25010 Quality Model
  • Usability
  • Reliability
  • Performance Efficiency
Evaluation Tools
  • 15-item questionnaire
  • 5-point Likert scale
  • Validated by the adviser
  • Direct observation
  • Automated test suite
Respondents (N = 15)
  • 1 Sports Coordinator
  • 3 faculty sports advisers
  • 11 student-athletes
Data Analysis
  • Weighted mean per criterion
  • Overall weighted mean
  • Scale: Table 1
  • Results in Section 5.3
DATABASE LAYER (MySQL)
Eloquent ORM relationships • versioned migrations • foreign-key constraints • private storage for eligibility documents and issued certificates
