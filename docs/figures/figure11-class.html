Figure 11. Class Diagram — SportsHub

Seventeen entities of the MySQL schema; the highlighted classes belong to the unified Messages & Follow-ups module.
User
  • id
  • name, email, username, password
  • role (Administrator / Student)
  • status, sport_id, student_id
  • phone, grade_level
  • emergency contact
  • profile_photo_path
  • must_change_password
Sport
  • id
  • name
  • classification, gender
  • description, status
  • logo_path
Coach
  • id
  • name, email, phone
  • specialty, coach_type
  • sport_id, status
  • profile_picture_path
Application
  • id, reference_number
  • name, student_id, grade, gender
  • email, sport_id
  • three document paths + statuses
  • status (Pending … Approved)
  • rejection_reason, review_notes
  • admin_instructions
  • reviewed_by, reviewed_at
  • review_history, athlete_id
ApplicationStatusHistory
  • id, application_id
  • status, notes
  • admin_instructions
  • changed_by
Notification
  • id, type
  • notifiable_type, notifiable_id
  • data, read_at
Event
  • id
  • title, description, venue
  • starts_at, ends_at, status
  • sport_id, event_type
  • coach_id, team_name
  • max_participants, notes
AttendanceSession
  • id, event_id, sport_id
  • title, venue, description
  • session_date, start_time
  • late_grace_minutes, status
  • created_by, opened_at, closed_at
Attendance
  • id, attendance_session_id
  • event_id, user_id
  • status (Present, Late, Absent…)
  • attended_on, check_in_time
MedicalRecord
  • id, athlete_id
  • examination_date, medical_status
  • next_checkup_date
  • findings, restrictions, notes
  • medical_certificate, archived_at
MedicalIncident
  • id, athlete_id, sport_id
  • incident_date, activity
  • injury_type, body_part, severity
  • description, treatment
  • rest_period_days
  • return_to_play_date
  • medical_clearance
Achievement
  • id, athlete_id, team_name
  • sport_id, event_id
  • title, description
  • achievement_type
  • competition, place
  • date_achieved, certificate_path
Message
Unified module
  • id, sender_id
  • subject, content
  • message_type, category
  • priority (Normal, Important, Urgent)
  • status (draft, sent)
  • recipient_type
  • event_id, medical_record_id
  • reply_to_message_id, sent_at
MessageRecipient
Unified module
  • id, message_id
  • recipient_id
  • is_read, read_at
MedicalFollowUp
Unified module
  • id, message_id
  • follow_up_type
  • scheduled_date, scheduled_time
  • location
  • additional_instructions
  • response_required
  • status (Scheduled … Cancelled)
  • completed_by, completed_at, cancelled_at
MedicalFollowUpRecipient
Unified module
  • id, medical_follow_up_id
  • recipient_id
  • read_at
  • acknowledged_at
  • completed_at, completed_by
  • status
CertificateRequest
  • id, achievement_id
  • student_id
  • status (Pending, Approved, Issued)
  • remarks, handled_by, handled_at
  • certificate_path
  • certificate_generated_at
  • certificate_reference
Announcement
  • id
  • title, body
  • published_at, status
  • event_id
